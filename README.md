# 🚗 BMW Sales Dashboard | Power BI

An interactive multi-page Power BI dashboard analyzing BMW sales across four models (M3, i8, X3, X6) for 2022–2024.

![Home](images/home.jpg)

## 🎯 Business Questions
- How do sales volume, average price, and engine size compare across the four models?
- Which colors and transmission types do customers prefer?
- How do these metrics change from year to year?

## 📊 Key Features
- **Home page** with navigation buttons to each model
- **KPI cards:** Average Price, Total Sales Volume, Average Engine Size
- **Year slicers:** 2022, 2023, 2024, and Select All
- **Donut chart:** Manual vs. Automatic transmission split
- **Bar chart:** Sales volume by color
- **Navigation arrows** to move between model pages

## 🔍 Key Insights
- Blue was the top-selling color for the i8, X3, and X6.
- Average price is very close across models (about 74.6K to 75.4K).
- Transmission split is nearly even (about 49% Automatic vs. 51% Manual).
